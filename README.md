# TaskManager - Mi gestor de tareas

## Descripción
TaskManager es una aplicación web que permite organizar y administrar tareas personales de manera sencilla.

## Funcionalidades
- Agregar nuevas tareas.
- Asignar prioridades a las tareas.
- Marcar tareas como completadas.
- Deshacer una tarea completada.
- Eliminar tareas.
- Guardar las tareas mediante localStorage.
- Mantener las tareas y su estado al actualizar la página.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Cómo utilizar la aplicación
1. Abrir el archivo index.html en un navegador.
2. Escribir el nombre de una tarea.
3. Seleccionar su prioridad.
4. Presionar el botón "Agregar tarea".
5. Utilizar los botones "Completar", "Deshacer" o "Eliminar" según sea necesario.
